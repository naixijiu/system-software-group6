## 复现与可选截图

在 Ubuntu/WSL 中进入“代码”目录，配置现有 RISC-V 工具链后执行：

```bash
make clean && make
make qemu
make grade
```

本机工具链不在 PATH 时可先执行：

```bash
export PATH='/opt/riscv/riscv64-unknown-elf-toolchain-10.2.0-2020.12.8-x86_64-linux-ubuntu14/bin':"$PATH"
```

其他机器以实际安装路径为准。普通启动约需 10 秒完成当前关机计数；评分包含 8、8、30 秒三个运行时段，另需编译时间。

报告已保存真实测试输出文字，不需要用伪造截图补证。若希望补一张总分截图，截取 make grade 末尾三项 PASS 和 Total Score: 100/100，保存到“报告/图片”，在报告中插入即可。原有三张截图属于 A 阶段记录。
